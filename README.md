# HeyPost Frontend

Frontend aplikasi kasir dan operasional HeyPost. Source lengkap frontend tersedia pada arsip `heypost-frontend.zip` di repository ini. Ekstrak arsip ke root repository untuk mendapatkan struktur source siap dikembangkan.

Frontend ini menggunakan API backend terpisah melalui endpoint same-origin `/api/trpc`. Tidak ada seed/mock data bisnis, QRIS palsu, atau identitas toko contoh.
